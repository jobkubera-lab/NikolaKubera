# Poster → Motion Prompt

Use this as a reusable structure, then replace bracketed fields with the actual scene.

## Prompt

Create a short cinematic motion sequence from the supplied KUBERALAB poster/reference image.

**Subject:** [machine / model if verified]
**Series:** [ARMORED POWER / MEGA YACHTS / MEGA TRACTORS / E-MOUNTAIN BIKES]
**Duration:** [for example 7 seconds]
**Format:** [9:16 / 16:9 / 1:1]

Preserve the exact recognisable machine design, proportions, materials, wheel/body geometry, visible accessories and colour relationships from the reference. Do not create a second copy of the machine and do not morph it into another design.

The scene begins immediately inside the established visual world. Use one clear cinematic action: [camera reveal / controlled acceleration / ocean glide / terrain climb / mechanical movement]. Environment and lighting should reinforce the series language without obscuring the subject.

Camera: [specific movement].
Lighting: [specific source and mood].
Environment: [specific setting].
Motion detail: [dust / water / tyre movement / suspension / reflections / restrained particles].

Keep the motion physically coherent. Avoid warped wheels, duplicated components, floating parts, broken reflections, random text, fake logos and unreadable branding.

If product specifications or manufacturer claims are not supplied, do not invent them.

End on a clean hero composition suitable for a campaign frame. Saturn seal ♄ may appear only as a restrained signature if requested.
