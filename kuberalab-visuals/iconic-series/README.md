# ICONIC SERIES — KUBERALAB Visual Operator Pack

A reusable production system for the four KUBERALAB machine worlds already defined in the parent project:

- ARMORED POWER
- MEGA YACHTS
- MEGA TRACTORS
- E-MOUNTAIN BIKES

The pack keeps still-image art direction, motion prompts, captions and quality review consistent without changing the existing KUBERALAB visual identity.

## Files

- `master-rules.md` — non-negotiable visual and brand rules.
- `poster-to-motion.md` — reusable static-to-motion prompt structure.
- `instagram-caption.md` — concise social caption template.
- `quality-checklist.md` — pre-publish review gate.

## Rule

Use the real source image/object as the anchor. Do not invent manufacturer claims, performance specifications, ownership, endorsements or product facts that are not supplied or verified.
